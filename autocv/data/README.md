# Bundled data

- `words.txt.gz` — *Webster's Second New International Dictionary* (1934) word list ("web2", 234,936 words),
  as distributed with BSD and macOS in `/usr/share/dict/web2`. Public domain (the 1934 copyright has lapsed).
  The fact-check uses it to tell ordinary English words from names of tools, products and organizations;
  bundling it makes the check behave identically on macOS, Windows and Linux.
- `fonts/Gelasio-*.ttf` — Gelasio by SorkinType (https://github.com/SorkinType/Gelasio), a free font with the
  same character widths as Georgia, used by LibreOffice when Georgia isn't installed. SIL Open Font License 1.1
  (`fonts/OFL.txt`).
